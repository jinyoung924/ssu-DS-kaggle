Overview
본 대회는 아마존(Amazon)에서 실제로 수집된 의류/신발/쥬얼리(Clothing, Shoes and Jewelry) 카테고리의 구매 및 리뷰 데이터를 기반으로 하는 Top-K 추천(Top-K Recommendation) 문제입니다.

쉽게 말하면, "이 사람이 과거에 어떤 옷/신발/액세서리들을 사거나 리뷰를 남겼는지"를 보고, "이 사람이 다음에 살 만한(관심 있어 할) 상품 20개를 골라내는" 문제예요. 실제 온라인 쇼핑몰이나 스트리밍 서비스에서 "이런 상품은 어떠세요?" 하고 띄워주는 추천 화면을 떠올리시면 됩니다.

여기서 "Top-K"는 정답을 하나만 맞히는 게 아니라, 모델이 각 사용자에게 추천할 상품 K개(이번 대회에서는 20개)를 제시하고, 그 안에 실제로 사용자가 관심 가진 상품이 얼마나 포함되어 있는지를 평가한다는 의미입니다.

Baseline(기준이 되는 기본 모델)은 사용자와 상품의 ID 정보만 이용해서 "비슷한 구매 패턴을 가진 사용자는 비슷한 상품을 좋아할 것이다"라는 아이디어로 추천하는 협업 필터링(collaborative filtering) 모델(예: LightGCN)입니다. 즉 상품이 어떻게 생겼는지, 이름이 뭔지는 전혀 몰라도 오직 "누가 무엇을 샀다"는 기록만으로 추천하는 방식이에요.

여기에 더해, 상품의 제목(title)이나 이미지 같은 부가 정보(메타데이터)를 추가로 활용해서 baseline보다 더 나은 성능을 만드는 것도 자유롭게 허용됩니다. 예를 들어 "이 상품 이미지가 이전에 산 상품과 스타일이 비슷하다"는 정보를 모델에 녹여내면 ID 정보만으로는 잡아내기 어려운 패턴까지 포착할 수 있습니다.

Evaluation
평가 지표는 Recall@20입니다.


Top20_u : 유저 u에게 추천한 상위 20개 아이템
GT_u : 유저 u의 test 정답(ground truth) 아이템
모든 유저에 대해 맞힌 아이템 수를 합산하고, 이를 정답 아이템 수의 합(유저당 최대 20개까지만 계산)으로 나눈 값입니다.

값이 높을수록 좋은 성능이며, 최종 순위는 마감 시점의 리더보드 점수 기준입니다.
