Dataset Description
본 데이터는 Amazon Reviews 2023 (McAuley Lab, https://amazon-reviews-2023.github.io/) 의 Clothing, Shoes and Jewelry 카테고리를 가공한 것으로, 비상업적 학술 연구 및 교육 목적으로만 사용할 수 있으며 대회 참가자 외 제3자에게 재배포할 수 없습니다.

데이터 개요
유저 수: 36,043명 / 아이템 수: 19,547개 / train interaction: 615,942건
유저와 아이템은 0부터 시작하는 정수 ID로 재부여되어 있습니다. (user_id: 0~36042, item_id: 0~19546)
test.csv의 모든 유저는 train.csv에도 등장합니다. 각 유저의 interaction 중 일부가 test로 분리되어 있으며, 정답은 공개되지 않습니다.
각 유저의 test 정답 아이템은 해당 유저의 train.csv에 등장하지 않습니다. 따라서 train에 이미 등장한 (user, item) 쌍은 추천할 필요가 없습니다.
Files
train.csv — 학습용 user-item interaction 데이터
test.csv — 추천 대상 user 목록 (정답 비공개)
sample_submission.csv — 제출 형식 예시 (실제 예측이 아닌 형식 확인용)
item_meta.jsonl — 아이템(상품) 메타데이터 (한 줄에 아이템 1개, JSON Lines 형식)
train_reviews.jsonl — train.csv의 interaction에 대응하는 리뷰 텍스트 (train.csv와 같은 행 순서)
Columns
train.csv

user_id — 사용자 ID
item_id — 아이템 ID
rating — 사용자가 매긴 평점 (1~5)
timestamp — 리뷰 작성 시각 (Unix time, 밀리초 단위)
test.csv

user_id — 추천 대상 사용자 ID (총 36,043명)
sample_submission.csv

user_id — 사용자 ID
item_id — 해당 사용자에게 추천하는 top-20 아이템 ID를 공백으로 구분하여 나열 (예: 15114 14020 3935 ...)
item_meta.jsonl (모든 아이템 19,547개가 포함되어 있으며, 값이 없는 필드는 비어 있을 수 있습니다)

item_id — 아이템 ID
title — 상품명
main_category — 대분류
categories — 계층형 카테고리 목록
store — 판매처/브랜드
features — 상품 특징 문구 목록 (bullet points)
description — 상품 설명 목록
details — 기타 상세 정보 (dict)
price — 가격 (USD)
images — 이미지 목록. 각 항목은 thumb, large, hi_res URL과 variant(MAIN, BACK 등)로 구성
average_rating, rating_number — 상품의 평균 평점 및 평점 개수
train_reviews.jsonl

user_id, item_id — train.csv와 동일한 키
title — 리뷰 제목
text — 리뷰 본문
helpful_vote — 리뷰에 대한 도움이 됨 투표 수
verified_purchase — 구매 인증 여부
메타데이터 활용 안내
메타데이터는 일부 불필요한 항목만 제외하고 원본 정보를 최대한 그대로 제공합니다.
모든 컬럼을 사용할 필요는 없습니다. 모델링에 필요한 컬럼만 골라서 불러와 사용하세요. (예: title, categories, images 등)
참고
평가 지표는 Recall@20이며, 제출 파일의 각 행에는 20개의 아이템 ID를 넣어 주세요.
Validation set은 별도로 제공되지 않습니다. train.csv에서 유저별로 약 10%를 랜덤하게 분리하여 validation으로 사용하는 방식을 권장합니다. (필수 아님)
